# Device List 
This repo has the main implementation of the two endpoints described in the spec.
There are two branches: 
1. main: which has full simple implementation
2. pagination-filtration: a branch where I additionally support pagination, sorting and filtration. PR can be found at https://github.com/hayamikkawi/dot-smart-traps/pull/1
